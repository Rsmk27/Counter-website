# Counter Website

A fully functional personal counter website with a clean, modern UI and mobile-responsive design. Track your progress with persistent local storage.

## Features

- ✨ Clean and modern user interface
- 📱 Fully responsive design (mobile, tablet, desktop)
- 💾 Persistent data storage using browser's local storage
- ⌨️ Keyboard shortcuts support (Arrow Up/+, Arrow Down/-, R for reset)
- 🎨 Smooth animations and visual feedback
- ♿ Accessible design with ARIA labels
- 🌙 Dark mode support

## Usage

Simply open `index.html` in your web browser to start using the counter.

### Controls

- **Increase Button**: Increment the counter by 1
- **Decrease Button**: Decrement the counter by 1
- **Reset Button**: Reset the counter to 0 (with confirmation)

### Keyboard Shortcuts

- `Arrow Up` or `+`: Increase counter
- `Arrow Down` or `-`: Decrease counter
- `R`: Reset counter

## Local Storage

The counter automatically saves your progress to your browser's local storage. Your count will be preserved even after closing the browser or refreshing the page.

## Browser Compatibility

Works on all modern browsers that support:
- HTML5
- CSS3
- ES6 JavaScript
- Local Storage API

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and responsive design
- `script.js` - Counter logic and local storage management
